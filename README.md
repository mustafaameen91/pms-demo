# tamm (تمّ)

Self-hosted, multi-tenant project management SaaS. Brand: [brand/README.md](brand/README.md).

**Stack:** Next.js 16 · TypeScript · Tailwind v4 + shadcn/ui · PostgreSQL 17 · Drizzle ORM · Better Auth

See [ROADMAP.md](ROADMAP.md) for phases and progress, and
[design-system/pms/MASTER.md](design-system/pms/MASTER.md) for the design system.

## Local development

Requirements: Node 20+, pnpm, Docker.

```bash
cp .env.example .env          # then set BETTER_AUTH_SECRET: openssl rand -base64 32
pnpm install
pnpm db:up                    # Postgres in Docker on port 5433
pnpm db:migrate               # apply schema
pnpm dev                      # http://localhost:3002
```

| Command | What it does |
|---|---|
| `pnpm dev` | Dev server on port 3002 |
| `pnpm build` / `pnpm start` | Production build / serve |
| `pnpm lint` | ESLint |
| `pnpm db:generate` | Create a migration after editing `src/lib/db/schema/*` |
| `pnpm db:migrate` | Apply migrations |
| `pnpm db:studio` | Browse the database |

## Structure

```
src/
  app/                   routes: (auth)/login|signup, onboarding, w/[slug] (workspace), w/[slug]/p/[key] (project)
  components/            ui/ (shadcn), shell/, projects/, tasks/, auth/
  lib/
    auth/                Better Auth config, client, session + workspace guards
    actions/             server actions (every one re-checks workspace membership)
    data/                read queries
    db/schema/           auth.ts (generated by Better Auth CLI) and pm.ts (projects, tasks, …)
  proxy.ts               redirects signed-out users to /login
drizzle/                 SQL migrations
```

## Email

Without SMTP settings, **emails are not sent**: invitations, password-reset links and notification
emails are printed in the terminal running the app. Invitations can also be shared with the
"Copy invite link" button on the Members page. To send real email, set `SMTP_HOST`, `SMTP_PORT`,
`SMTP_USER`, `SMTP_PASSWORD` and `EMAIL_FROM` in `.env` (see `.env.example`) and restart.

## Billing (manual payments)

One paid plan ("Pro"). New workspaces are locked until a platform admin records a payment at `/admin`
(set `SUPER_ADMIN_EMAILS` in `.env`). `TRIAL_DAYS` (default 0) gives new workspaces a trial instead.
Price and "how to pay" text are edited in the admin panel.

## Files

Receipts are stored on disk in `UPLOAD_DIR` (default `./uploads`, git-ignored) and served only to
workspace members via `/api/files/receipts/[expenseId]`. **Back this folder up together with the database.**

## Tests

`pnpm test` runs the unit tests for the accomplishment and budget calculations (`tests/`).

## Multi-tenancy

A workspace is a Better Auth *organization*. Every PM table has a `workspace_id`.
Pages call `requireWorkspace(slug)` and server actions call `requireWorkspaceById(id)`,
which return 404 / throw for non-members.
